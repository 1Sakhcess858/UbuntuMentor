\# UbuntuMentor



A mentorship and career guidance Android app for South African youth.



\---



\## Purpose



UbuntuMentor is a mobile application designed to connect South African youth with mentors, career guidance, and verified opportunities. The name combines "Ubuntu" — the Southern African philosophy of humanity and interconnectedness — with "Mentor," reflecting the app's core mission.



This prototype was built as part of the Open Source Coding (Intermediate) module (OPSC6312) at The Independent Institute of Education (IIE).



\---



\## Features



| Feature | Description | Status |

|---------|-------------|--------|

| \*\*User Registration\*\* | Users can create an account with name, email, and password | Working |

| \*\*Password Encryption\*\* | Passwords are hashed using SHA-256 before storage | Working |

| \*\*User Login\*\* | Users can log in with their credentials | Working |

| \*\*Settings\*\* | Users can change app language (English, isiZulu, Afrikaans) | Working |

| \*\*Local Data Storage\*\* | User data stored securely using SharedPreferences | Working |

| \*\*Logout\*\* | Users can log out and return to the login screen | Working |
